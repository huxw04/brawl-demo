# 多人联机十分钟试玩检查单

这份检查单用于阶段 C5b 的真实局域网验收。目标不是重新检查技能数值，而是确认房主权威模式在真实网络中可操作、可恢复，并能定位偶发问题。

## 测试准备

- 两台电脑使用同一版游戏，连接同一局域网；关闭旧版本进程。
- 房主创建房间，客户端通过房主局域网 IP 加入。
- 双方进入战斗后按 F3 打开联机诊断；F1 只用于正常返回菜单。
- 建议录屏，至少记下发生问题的大致时间、双方英雄和当时按下的技能。

## 十分钟流程

1. **0–2 分钟：基础移动。** 双方连续右键换点、穿插跳跃和翻滚；故意耗空一次体力，观察客户端是否出现长时间停住、回拉或错误恢复体力。
2. **2–4 分钟：近战与持续技能。** 使用 Cheems/刀盾狗/奶龙，测试追击普攻、格挡、滚动、喷火的开始、松开和主动取消。
3. **4–6 分钟：投射物与钩爪。** 使用贝爷或褚赢，连续测试飞刀、钩爪、棋子；观察是否出现永不消失的投射物、命中特效重复或钩爪动作与位置分离。
4. **6–8 分钟：世界实体。** 测试刀盾狗 W 二段、褚赢 Q/W/R；重点观察迟到的棋子、爆炸和禁锢是否最终自动补建或清理，角色是否能错误跑出权威禁锢。
5. **8–10 分钟：长动作与死亡恢复。** 测试 Cheems R、刀盾狗变身、褚赢传送；双方各死亡和复活至少一次。确认 HUD 倒计时约 3 秒，复活点不与存活敌人重叠，头顶显示约 1.5 秒“复活保护”，保护期间伤害和控制无效，结束后可正常受击并继续移动施法。

结束前分别截图或抄下 F3 面板：

- 房主：权威 Tick、命令序列、实体数。
- 客户端：旧角色包、旧实体包、旧事件、快照补建、快照补删、当前实体数。

旧快照计数增加本身不是故障，说明迟到数据被安全拒绝；补建/补删增加也不是故障，说明完整快照执行了恢复。真正需要报告的是计数增加后仍长期残留错误状态，或操作持续失效超过约一秒。

## 通过标准

- 连续十分钟没有闪退、不可恢复失步或永久失去操作；
- 短暂抖动后，位置、生命、CD、体力和世界实体会自行收敛；
- 技能开始/取消不会永久卡住，死亡复活后仍可正常操作；
- 若客户端手感明显差于房主，即使状态最终正确，也记录具体场景，作为是否加入本地移动预测的依据。
## 比赛计分与结算

- 击杀后所有窗口只出现一次相同的全局播报，连续击杀文案按次数递进。
- 一名玩家达到三连杀后被击杀，应显示“终结”，而不是击杀者的普通连杀文案。
- 平时比分栏只显示自己；按 `Tab` 展开后，各窗口的击杀/阵亡/助攻一致。
- 达到 10 击杀或倒计时结束后，所有窗口停止角色操作并显示同一结算结果。
- 结算页的伤害与承伤统计不包含超过目标剩余生命的溢出伤害。
