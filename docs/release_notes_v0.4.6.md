# Brawl Demo v0.4.6：第一可玩版本

发布日期：2026-08-31

这是项目第一批五名英雄和局域网乱斗流程的可玩版本，适合课程展示和同学试玩。

## 主要内容

- Cheems、刀盾狗、贝爷、奶龙、褚赢五名英雄。
- 四方庭院、回风峡谷、残棋台三张地图。
- 角色实验室与本地 Bot 战斗。
- 2～4 人房主权威局域网自由乱斗。
- 五分钟或十次击杀的比赛规则、三秒安全复活和短暂无敌保护。
- K/D/A、输出、承伤、治疗、击杀播报、连杀与终结提示。
- 地图、英雄和关键世界效果的同步，以及网络诊断信息。

## 下载

下载 `BrawlDemo-v0.4.6-windows-x86_64.zip`，完整解压后运行 `BrawlDemo.exe`。运行试玩包不需要安装 Godot。

Windows 可能提示“未知发布者”，因为课程试玩版本没有代码签名证书。请只运行从本仓库 Release 页面下载的文件。

SHA-256：`9A6E11B16081ED1CDB53BE05D5465A0CB661ABBDB06041E8EB6C84B84D36F2D3`

## 联机提示

- 所有玩家必须使用 v0.4.6。
- 一名玩家创建房间，其他玩家输入房主的局域网 IPv4 地址。
- 默认使用 UDP `24567`，必要时允许游戏通过 Windows 专用网络防火墙。
- 房主退出会结束房间；当前不支持公网自动组房、房主迁移和断线重连。

## 已知问题

- 高延迟下客户端可能感受到操作反馈延迟和快速位移的小幅修正。
- 英雄平衡与三张地图仍需要更长时间的多人试玩。
- 美术完成度不完全一致，音效尚未系统接入。
